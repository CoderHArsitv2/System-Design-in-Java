# ✈️ Airline Management System

A Java-based **Low-Level Design (LLD)** implementation of an Airline Management System.

## Features

- Flight search and management
- Passenger management
- Flight booking
- Payment handling
- Booking management

## Design Concepts

- Object-Oriented Design
- SOLID Principles
- Factory Design Pattern
- Separation of Concerns
- Service & Manager layers
